Ce dossier contient la version autonome du site de l’Orchestre Symphonique des Dômes.

Pour l’ouvrir sur l’ordinateur, ouvrir index.html. Les 84 pages comprennent la page de recherche. Les pages, styles, scripts, polices, documents et fichiers audio nécessaires sont inclus dans ce dossier. Les vidéos restent sur YouTube ; les liens vers la billetterie et les artistes sont conservés. Les icônes des réseaux sociaux et leurs liens ont été supprimés de toutes les pages. La carte de contact utilise Google Maps.

Le formulaire de contact prépare un e-mail dans la messagerie du visiteur, à destination de osdomes.contact@gmail.com. Aucun serveur de l’ancien site n’est utilisé. Le destinataire peut être modifié dans contact-config.js. Le bouton n’affiche pas de confirmation d’envoi : le visiteur doit envoyer son message dans sa messagerie.

Pour publier sur GitHub Pages :

1. Importer uniquement le contenu de ce dossier dans le dépôt destiné au site. Conserver tous les sous-dossiers et le fichier .nojekyll. Git ou GitHub Desktop permettent de transférer les fichiers audio volumineux.
2. Dans les paramètres du dépôt, ouvrir Pages et sélectionner la publication depuis la branche principale, à la racine du dépôt.
3. Après publication, vérifier l’accueil, Concerts, Médias, Recherche et Contact depuis l’adresse fournie par GitHub.
4. Le nom de domaine personnalisé pourra être configuré après validation du nouveau site.

Les chemins relatifs permettent une publication à la racine d’un domaine ou dans le sous-dossier d’un projet GitHub Pages. Aucune compilation n’est nécessaire. Ne pas importer les archives de travail ni les sauvegardes conservées à côté de ce dossier.

Le site pèse environ 990 Mio, essentiellement à cause des 40 enregistrements. Leur contenu sonore a été conservé. Il reste environ 34 Mio avant le seuil de 1 Gio utilisé par l’action de déploiement GitHub Pages ; tenir compte de cette marge lors de futurs ajouts.
